title: Getting started
summary: Run the site and make it yours.
---

Run `go run .` in this directory and open http://localhost:8090.

## Make it yours

- The site's name, address and description are in `main.go`.
- The landing page is `content/index.md`. See [The landing page](./landing.md).
- The pages are in `content/docs`. See [Writing a page](./writing.md).
